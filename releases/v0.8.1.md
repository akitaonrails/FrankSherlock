# v0.8.1

### Improvements

- **Ollama model override settings**: The vision model is no longer hardcoded — a settings override lets you pick which installed Ollama model handles classification, documented in the README.

- **Better default model on Windows NVIDIA 8GB GPUs**: Model selection now avoids recommending `qwen2.5vl:7b` on Windows machines with 8GB NVIDIA cards, where it does not fit comfortably in VRAM.

### Bug fixes

- **Scan no longer aborts on unreadable files** (#11, thanks @EduardoLacusta): A single file that could not be opened — restrictive ACLs, an exclusive lock held by another process, a cloud placeholder that fails to hydrate — killed the entire scan job with an unhelpful `io error: Access denied` and zero files indexed. Unreadable files are now skipped with a warning naming the path, the scan cursor advances past them so resume works, and a total is logged at the end of the phase. A follow-up fix ensures an already-indexed file that becomes temporarily unreadable keeps its index entry instead of being treated as deleted.

### Test suite

- Added App-level Vitest coverage for shell rendering, sidebar collapse, CLI auto-scan startup behavior, and tool-mode switching (#10, thanks @jadsongmatos).
- Hardened App test isolation with typed fixtures and restored spies between tests.
- New Rust regression tests for scans over unreadable files.
- 343 Rust tests, 332 frontend tests.

### Maintenance

- Updated Rust and frontend dependencies, clearing all outstanding `cargo audit` advisories (crossbeam-epoch, quick-xml, rkyv). Tauri moves to 2.11.x across the Rust and JS sides.
- Cleared Rust clippy warnings in PDF page detection, query parsing, video metadata extraction, Tauri command wrappers, and face-clustering tests so the CI clippy gate is green again.
- Fixed CI runtime compatibility in the GitHub Actions workflows.
